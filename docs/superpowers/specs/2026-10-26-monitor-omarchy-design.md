## 1. 目的与已确定方向

将 `with5/komari-theme-omarchy` 移植为可以安装在 Monitor Hub 上的独立公开状态页主题。用户已确定“尽量原样移植，先编写设计文档”。

“原样”的优先级是保留上游可辨识的视觉和交互：ASCII 横幅、终端文本框、btop 风格仪表、字符历史图、配色、中英文、快捷键、屏保、首页与详情结构。实际数据含义和错误处理必须遵循 Monitor 协议；存在冲突时调整数据标签和状态，不伪造上游功能。

沿用原生 JavaScript ES Modules，拆出 Monitor 数据适配模块。独立目录、独立主题标识、独立版本与后续 Git 仓库；不复制广告墙页面、样式、皮肤或计算器。

本文件记录目标行为和设计选择，不是实现任务清单，也不代表已经通过兼容测试。

## 3. 方案比较与选择

| 方案 | 收益 | 代价 | 结论 |
| --- | --- | --- | --- |
| 保留原生 ES Modules，增加 Monitor 适配层 | 保留原绘制、排版、动画和键盘逻辑，视觉差异容易控制 | 需要重新划清原来混在 `app.js`、`detail.js` 中的数据职责 | 采用，符合用户确认的原样移植方向 |
| 用 React + TypeScript 重写界面 | 便于使用 React 生态和组件类型约束 | 重做文本绘制和交互，更容易偏离上游，工作量更大 | 本次不采用 |

工程决定：使用 npm 管理开发工具，Vite 负责本地代理与静态构建，提交锁文件；应用运行时仍为原生 ES Modules，不引入 React、Radix 或 Recharts。纯 JavaScript 模块用 JSDoc 描述接口类型，运行时校验负责应对不可信响应。具体开发依赖版本在实施时确定并锁定。

## 5. 界面和交互

### 5.1 首页

顺序保持上游：横幅 → 在线数量 / 上下行速率 / CPU 汇总 → 分组和配色选择 → nodes 分隔线 → 节点卡片 → 固定底部状态栏。

首页卡片保持上游的信息密度：名称、分组、在线状态、运行时长、国家、系统、CPU 仪表与短期字符历史、内存、磁盘、上传与下载速度。累计流量、费用和到期等补充信息主要放详情，避免将首页改成 Monitor 默认卡片布局。

节点初始顺序和分组首次出现顺序尊重 Hub 输出，不沿用 Komari 的 `weight` / 名称排序。全部、未分组、任意真实分组使用不同的内部状态；真实分组名可以是 `all`、`none`、`*` 或“全部”。

汇总范围采用当前分组和搜索结果，与可见卡片一致。在线数量以 `online` 为准；CPU 和网速仅汇总有效指标，不将等待上报节点计为 CPU 0%。没有有效指标时显示 `—`。这是为满足 Monitor 数据语义而对上游汇总逻辑作出的明确修正。

### 5.2 详情概览

保留上游机器配置框、实时资源框和延迟摘要框。字段按 Monitor 能力显示：

- 系统、架构、虚拟化、内核、CPU 名称及核心数、容量、国家、分组。
- 货币与付款周期、到期日期与 Hub 剩余天数、额度与周期用量、累计上下行、公开备注。
- 实时 CPU、内存、磁盘、swap、负载与连接数等已有布局可以容纳的指标。
- CPU、内存使用量、网速等历史曲线；Monitor 不提供的历史负载不绘制假曲线。

实时使用率使用同一次采样的已用量和总量。历史响应没有同期容量时，内存历史采用字节单位，避免以当前容量反算并声称是历史使用率。标签和图轴同时调整，字符绘制风格保留。

价格 `0` 显示免费，不因假值判断隐藏；到期 `0` 显示今天到期；未设置到期日期、额度不限和数据不可用分别表示。

### 5.3 延迟页

保留探测任务列表、字符曲线、丢包位置提示、时间范围和单任务放大。Monitor 的 `ping`、`probes`、窗口级 `loss` 直接进入独立视图模型，不伪装成 Komari 原始采样。

统计显示规则：

| 上游显示 | Monitor 移植规则 |
| --- | --- |
| last | 改为“最近时间桶”延迟，明确不是最新单次探测 |
| avg | 首版不展示全窗口精确平均值，现有接口不足以还原 |
| min / max | 仅当范围内所有有效桶均带有效 `band` 时由其求范围最小 / 最大，否则 `—` |
| loss | 使用响应顶层按任务给出的窗口丢包率；该映射存在时，缺失任务项按协议为 0；整个映射缺失时显示不可用 |
| p50 / p95 / p99、stddev、jitter、样本数 n | 首版移除，不能从桶中位数精确恢复原始样本统计 |
| 任务类型与探测间隔 | 标准公开响应没有对应元数据时不显示 |

每桶 `latency` 是桶中位数，`null` 不绘制成 0 ms。桶级 `loss` 用于丢包标记，`band` 可用于范围提示；缺失桶留空。跨桶重采样保留间隙和丢包标志，不将桶百分比简单平均为窗口丢包率。

### 5.4 路由与快捷键

工程决定：保留 hash 路由，列表为 `#/`，详情为 `#/node/<Monitor id>`。外层路径仍是 `/`，不必把详情改为默认主题的路径路由。直接打开、刷新、复制详情链接和浏览器前进 / 后退都必须可用。

保留 `h/j/k/l`、方向键、`gg/G`、`0/$`、数字前缀、`Enter`、`u/Esc`、`/`、`H/L`、`t/T`、`r`、`s`、`i`、`a`、`?` 以及详情切页 / 范围 / 刷新键。移除解锁页后同步修改 Tab 循环和中英文帮助。

输入框、选择控件、可编辑元素内不截获普通文本快捷键，也不干扰输入法组合输入和浏览器系统组合键。首页卡片具备可访问名称、键盘焦点和进入详情能力。原版 Vim 导航作为增强，不替代正常 Tab 操作。

### 5.5 视觉保真、中文与移动端

- 保留上游 CSS 变量、字体栈、文本行高、终端框和配色值。
- 保留宽字符固定双单元格的 `.cj` 机制，检查中文、混合名称、emoji、组合字符与长分组。
- 不要求用户安装专属字体；系统字体回退下页面仍能阅读。首版不引入外部字体 CDN。
- 桌面以 1200×680 的上游预览比例作对照，并检查 1600×1000；移动端检查 320、375、390、768 CSS px 宽度。
- 小屏允许改变卡片字符宽度、控件换行和状态栏次要信息显隐，整体页面不横向溢出，主要操作可触达。
- 桌面目标是同配色、同数据、同语言下保留原版结构、比例和字符风格；差异仅来自 Monitor 必需字段语义与兼容修正。
- 减少动效开启时展示静态横幅、停止屏保和持续动画；运行中切换系统设置也应生效。

### 6.1 启动和节点映射

启动时并行读取 `/api/me`、`/api/nodes` 与 `/api/themes/{short}/config`。配置失败走默认值；节点请求失败进入明确错误状态；空数组是有效空站点，不用演示节点替补。

Monitor 对外读取的节点快照不是 agent 的 JSON-RPC 上报。接口响应按 Monitor 自身结构解析，不沿用 Komari `{status,data}` 通用解包，也不请求 `/api/public`、`/api/clients` 或 `/api/rpc2`。

| Monitor 数据 | 视图用途 |
| --- | --- |
| `id` | 唯一标识；转换为字符串作路由和 Map key，禁止复用 Komari UUID 假设 |
| `name`、`group`、`country`、`os` | 名称、分组、国家 / 系统说明 |
| `online` 与有效 `metrics` | 分开确定连接状态和指标可用性 |
| `metrics.cpu` | CPU 百分比 |
| `metrics.mem_used` / `mem_total` | 实时内存与使用率 |
| `metrics.disk_used` / `disk_total` | 实时磁盘与使用率 |
| `metrics.net_tx` / `net_rx` | 上传 / 下载 B/s，方向不可反转 |
| `total_*`、`month_*`、`day_*` | Hub 累计结果 |
| `month_used`、`traffic_mode`、`traffic_limit` | 当前周期计费用量与额度 |
| `expires_in`、`last_seen_ago` | Hub 日期与时钟下的相对时间 |
| `public_remark` | 公开备注 |

校验响应顶层、节点基本形状和指标有限数值。坏节点不导致全站白屏；部分指标异常不清空该节点其他有效基础信息。离线、等待首次上报、异常指标在视图模型中保留不同状态，不能都折叠成离线。

### 6.2 实时连接

采用单一数据协调器供首页和详情共享快照，不在每张卡片或详情内重复创建连接。

- 支持解压时连接 `/api/ws?gzip`，否则 `/api/ws`，协议跟随页面使用 `ws` / `wss`。
- 兼容文本与 Blob 压缩帧。解码队列按到达顺序串行处理，一帧失败不阻塞后续帧。
- 每次连接、暂停和恢复具有代际标识；旧连接和旧请求完成后不能提交结果。
- REST 开始时记录快照版本；期间已收到新快照，则丢弃旧 REST 结果。
- 仅成功解码、解析并接受的快照重置断流计时。持续坏帧也会触发恢复。
- 首次连接、断线或静默超时时立即获取列表，以 5 秒轮询兜底，继续重连；收到有效 WebSocket 快照后停止轮询。
- 工程初始参数：10 秒无有效帧视为静默，5 秒重试；避免重试计时器叠加、请求无界重叠。参数可根据实际验证调整，但不改变兜底行为。
- 页面隐藏时关闭连接、暂停轮询和重试、失效化在途结果；恢复可见时立即请求并重连。
- 401 清除已无权展示的节点及历史缓存，进入需要登录状态；403 与网络 / 服务错误分别显示合适信息。
- 保留最后成功数据时标明实时更新中断；有效新数据到达后解除。隐藏页面不继续报告虚假的连接健康。

首页短期 CPU / 网速字符图仅是会话内采样，不作为累计流量来源。节点删除清理缓存；断流和后台恢复产生的时间间隙不得画成连续采样。

### 6.3 HTTP、历史和错误

- HTTP 请求有超时、可取消和有界重试；参考旧项目行为但不让暂停后继续重试。
- Hub 的 `text/plain` 错误作为安全文本显示；HTML / CDN 拦截页仅按状态给说明。200 非 JSON 也进入数据错误状态。
- 时间范围根据 `history_days` 动态生成，包含保留期本身；缺字段兼容按 7 天。切换保留期时同步收窄当前范围。
- 历史请求按当前页签选择 `series=metrics` 或 `series=ping`；`points` 根据字符绘制宽度在 60–1440 内选择。
- 使用 Hub 返回的 `step` 与时间戳定位，不把稀疏点当固定频率原始采样。`minutes` 不足与最后未结束桶分别处理。
- 历史峰值字段存在时可标注峰值；缺失时只呈现现有均值，不补零。
- 详情切节点、切范围、切页签时，旧结果不得覆盖新状态。同键在途请求合并，缓存有界，失败不永久缓存。
- 当前页签可每 30 秒刷新历史，隐藏、离开详情或卸载时停止；`R` 可主动刷新，历史失败不影响实时资源。

### 6.4 流量和时间

总量、本期与今日流量消费 Hub 结果，不对网速或历史积分记账。优先使用有效 `month_used`；旧版缺少时根据已知 `traffic_mode` 和 Hub 给出的 `month_rx/month_tx` 推导，未知模式显示不可用。

不自行判断周期边界或重置 Hub 数值；`month_start` 等响应信息用于说明。额度为 0 代表不限，不显示为已用尽；超额允许显示真实超额数值，仪表绘制可封顶但文字不截断。

`expires_in` / `last_seen_ago` 明确为 `null` 时不做旧版回退；只有 key 不存在时才允许按旧字段估算，并承认依赖访客时钟。离线时长只在 `online === false` 时显示。

货币用带异常保护的 `Intl.NumberFormat`；付款周期兼容命名值、`<n>m` 与 `once`，不把一次性当月付，不假设所有月份都是 30 天。

## 7. 配置、偏好与安全文本

### 7.1 站点配置

拟定独立 `short` 为 `monitor-omarchy`、初始版本 `0.1.0`，均为工程提案；最终显示名、作者、GitHub URL 在发布前填写真实值，不冒用上游作者或仓库。`short` 满足安装和预览子域名规则，正式收录前仍需核实唯一性。

将上游 `configuration.data` 转换为 Monitor `config`：

| key | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `language` | select | `auto` | `auto/en/zh` |
| `palette_dark` | select | `tokyo-night` | 当前 23 套配色之一 |
| `palette_light` | select | `catppuccin-latte` | 同上 |
| `allow_switch` | boolean | true | 关闭时忽略旧的访客配色选择 |
| `show_group` | boolean | true | 隐藏筛选控件，不删除节点 |
| `banner` | string | 空字符串 | 空时使用站点名 |
| `intro` | select | `random` | 原版五种效果、random、off |
| `screensaver` | boolean | true | 90 秒空闲屏保，减少动效优先 |

默认值在 `theme.json` 单点声明；构建时读取。保存配置仅覆盖类型、选项和范围有效的项。配置请求失败静默用默认值，不影响节点获取。

首版使用 Hub 后台设置界面，不实现主题内保存配置或额外 PUT 接口。站点配置中不设计密钥和内网地址字段。

### 7.2 访客偏好

配色和语言使用独立的 `monitor-omarchy:*` 存储键，读写及访问 `localStorage` 本身均保护异常。不可存储时当次操作仍生效，刷新后恢复默认。

语言优先级：合法访客选择 → 明确站点默认 → 浏览器语言 → 英文；移除 Komari `language` Cookie 依赖。配色优先级：站点允许切换时的合法访客选择 → 根据系统深浅色选择站点默认 → manifest 默认。

### 7.3 文本与公开视图

节点名称、分组、系统字符串、备注、公告 / 横幅文字与错误信息都按不可信文本处理。页面使用 DOM 文本节点或 `textContent` 写入外部值；不得把接口字符串直接交给 `innerHTML`。

上游用 HTML 字符串生成文字框的部分需要改造：固定绘制标记可保留，但外部文字通过明确的文本片段进入渲染器，不能直接拼接；安全性通过注入用例验证。

保持上游公开页取向：即使登录后响应含私有字段，也不显示 IP、hostname、私有 remark、token。主题只使用明确列入公开展示模型的字段；界面隐藏不是访问控制。

## 8. 兼容策略

首版以既有项目采用的 Hub 1.4.1 接口形状作为开发基线，并在交付时实际可获得的最新版 Hub 上验证；这不表示 1.4.1 是当前最新版。针对文档列出的缺失字段做能力检测，不承诺未测试的旧版本完整兼容。

降级项包括：无 gzip 时文本帧、无配置接口时默认值、无 group 时未分组、无 history_days 时 7 天、无历史峰值 / 新字段时不展示对应信息、无相对时间字段时旧字段估算。未知新增字段忽略。

目标浏览器为实施时可获得的 Chromium、Firefox、WebKit 当前版本，桌面与手机尺寸均验证。缺少 DecompressionStream 可降级；其他浏览器 API 做能力检测，不能因某一增强功能缺失使整个主题白屏。README 仅声明实际验证过的范围。

官方主题预览站在窗口上下文拦截 API，因此请求和 WebSocket 保持在主页面，不搬入 Worker / Service Worker。

站点图标使用固定 `/favicon.svg`，`index.html` 保留原样 href，页面若展示 logo 也引用该路径。提供不透明底色的 180×180 `/apple-touch-icon.png`，保证 Hub 自定义图标可替换。

## 11. 风险与实施者可决定的事项

| 风险 | 约束 / 处理 |
| --- | --- |
| 适配时只改端点，保留错误数据假设 | 使用明确 Monitor 视图模型，逐项校验，去除 Komari RPC 和 UUID 依赖 |
| 字符排版在中文或手机失配 | 复用宽字符机制，多系统字体回退检查，必要时只修正尺寸计算 |
| 聚合延迟被当原始采样 | 用桶语义标签，移除不可恢复统计，不平均丢包率 |
| 异步请求和连接恢复导致旧数据回写 | 连接代际、请求版本、可取消操作与有界缓存 |
| 源码路径重构后静态资源失效 | 用 Vite 管理源码资源，固定图标路径单独保留，实际安装验证 |
| 上游后续变化影响验收 | 固定来源提交，更新单独检查差异 |

实施者可自行决定：模块细分、开发工具版本、测试工具的必要开发依赖、内部缓存上限、同等行为的 DOM 渲染方式、截图自动化与临时测试数据组织。不得借此增加新视觉风格、恢复无数据源的统计或引入外部业务 API。

待用户审阅的是整体设计及少量工程提案：保留 hash 路由、首页汇总跟随筛选、原生 ES Modules + Vite、拟定短名 / 初版版本，以及延迟页统计降级。确认设计后再编写实施计划，不在此阶段搭建应用或安装依赖。
