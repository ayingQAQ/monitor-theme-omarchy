# Omarchy · Monitor v0.1.0

首个 Monitor 移植版本。基于 with5/komari-theme-omarchy，保留 Omarchy 终端式视觉，重新接入 Monitor 数据协议。

## 安装

在 Monitor 后台「主题 → 从 GitHub 安装」填写：

```text
https://github.com/ayingQAQ/monitor-theme-omarchy
```

也可下载附件 `theme.tar.gz` 后在后台上传。不要使用 GitHub 自动生成的 Source code 压缩包。`theme.tar.gz.sha256` 用于完整性校验。

## 功能

- ASCII 横幅及五种效果、终端字符框、btop 仪表和字符历史图。
- 23 套配色、中英文、分组搜索、Vim 快捷键、90 秒空闲屏保。
- Monitor 节点详情、资源历史、延迟曲线、费用、到期与流量。
- 文本/gzip 实时推送、顺序解码、断线重连、轮询兜底和后台恢复。
- 手机布局、中文对齐、禁用存储兼容、安全文本和减少动效。
- 实心与点阵仪表统一单元格尺寸，修正字体回退导致的错位。

## 与 Komari 原版的差异

- 移除没有 Monitor 标准数据源的 unlock-test 解锁页面。
- 延迟采用 Hub 时间桶中位数和窗口丢包率，不伪造原始采样百分位数或抖动。
- 累计流量以 Hub 统计为准，历史范围跟随 Hub 保留期。

## 验证与限制

- 14 项 Node 测试、51 项 Chromium / Firefox / WebKit 浏览器检查通过。
- 生产构建、编译产物冒烟检查、安装包根目录/体积/gzip 校验通过。
- 尚未在真实 Monitor Hub 上验证上传安装、设置持久化及升级；未测试实体手机。
