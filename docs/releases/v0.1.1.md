# Omarchy · Monitor v0.1.1

- 首页按可用宽度自动调整卡片尺寸，中等窗口优先排成两列，减少左右留白。
- CPU 历史图改为紧凑单行，缩短卡片高度，保留终端字符视觉。
- 默认配色改为 Catppuccin；配色选择器及底栏操作统一为终端方括号文字风格。
- 精简 README，保留安装、预览、功能、配置和许可说明。
- 配置 GitHub Actions：推送 `v*` 标签后自动测试、构建、校验并发布正式 Release。

## 安装

Monitor 后台「主题 → 从 GitHub 安装」填写：

```text
https://github.com/ayingQAQ/monitor-theme-omarchy
```

也可下载附件 `theme.tar.gz` 上传安装。校验文件为 `theme.tar.gz.sha256`；请勿使用 Source code 压缩包。
