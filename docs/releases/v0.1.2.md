# Omarchy · Monitor v0.1.2

- Ping 延迟改为响应式折线图，加入时间轴、延迟刻度、采样点和丢包标记。
- 缺失时间桶和长时间断流处断开折线，不再用点阵面积图表现延迟。
- 配色选择器按当前文字自动收窄，移除固定留白和矩形焦点框，保留键盘焦点下划线。
- GitHub 仓库简介改为中文，README 预览同步更新。
- 首页使用弹性列铺满可用宽度，避免字体加载后列数变化及两侧大片留白。
- 资源条的已用、未用区域统一使用点阵纹理，仅以颜色区分。

Monitor 后台的 GitHub 安装地址：

```text
https://github.com/ayingQAQ/monitor-theme-omarchy
```

手动安装请下载 `theme.tar.gz`，校验文件为 `theme.tar.gz.sha256`。
